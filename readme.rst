# Sistem Rekomendasi Kuliner Labuan Bajo

Aplikasi web sistem rekomendasi kuliner di Labuan Bajo berbasis PHP (CodeIgniter 3) dan MySQL.

## Teknologi
- PHP (CodeIgniter 3)
- MySQL
- HTML, CSS

## Instalasi
1. Clone repository ini ke folder `htdocs` (XAMPP).
2. Buat database baru di phpMyAdmin dengan nama `sistem_rekomendasi_kuliner_labuanbajo`.
3. Import file `sistem_rekomendasi_kuliner_labuanbajo.sql`.
4. Sesuaikan konfigurasi database di `application/config/database.php` jika perlu.
5. Buka `http://localhost/rasa_bajo` di browser.
